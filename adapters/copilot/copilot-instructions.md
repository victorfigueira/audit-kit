## Code audits (audit-kit)
- To run a code audit, follow `audit-kit/RUN.md`. Standard mode by default; Full mode when asked.
- Audit operations are strictly read-only: generate findings and reports only inside `audit/`. Never edit repository code during an audit.
- Follow `audit-kit/RULES.md` for severity ratings (Critical, High, Medium, Low) and evidence standards.
- All audit output, code comments, commits, and documentation must be in English.
